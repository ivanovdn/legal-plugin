# Design specs

> Part of the [project wiki](../../wiki.md).

One spec per feature, written before it was built: the problem, the design and what was left out. A spec's own *Status* line is as of the day it was written; the status below is current, from [shipped-log.md](../../shipped-log.md) and [roadmap.md](../../roadmap.md). What goes in a spec rather than a decision note: [decisions/README.md](../../decisions/README.md). Newest first.

- 2026-10-15 · [What attorneys do to the document](2026-10-15-document-changes-design.md) — SP4 of pilot tracking: keep the document's text each turn, the pane's captures with their tracked changes, and the full text of every Apply, so what the model proposed can be compared with what the attorney kept. *Shipped (`feat/document-changes`); follow-ups on the roadmap.*
- 2026-10-14 · [Pane activity and the Caddy logs](2026-10-14-pane-activity-design.md) — SP3 of pilot tracking: record what happens in the pane between turns (opens, tabs, Finalize, errors, the wait) and keep Caddy's access logs for requests that never reach the backend. *Shipped (`feat/pane-activity`).*
- 2026-10-09 · [Per-turn record (`turn_log`)](2026-10-09-turn-log-design.md) — SP2 of pilot tracking: one durable row per accepted request, failures included, whose outcome is the same value as the trace's `app.outcome`. *Shipped (`feat/turn-log`).*
- 2026-09-16 · [Trace coverage](2026-09-16-trace-coverage-design.md) — make spans say when the app degrades instead of raising: ERROR only when the attorney got no answer, one root-level outcome field, and a closed vocabulary of degradations. *Shipped (`feat/trace-coverage`).*
- 2026-08-26 · [Automatic Compaction](2026-08-26-automatic-compaction-design.md) — fire compaction without a click, decided on the backend and obeyed by the pane. *Shipped (`feat/auto-compaction`).*
- 2026-08-25 · [Context Counter and Attorney-Triggered Compaction](2026-08-25-context-compaction-design.md) — a context gauge in the pane and a Condense button that replaces older chat turns with validated quotes, so truncation becomes avoidable. *Shipped (`feat/context-compaction`).*
- 2026-08-21 · [Context Budget and Loud Truncation](2026-08-21-context-budget-design.md) — fix two silent bugs that had the model answer about text it never saw, and tell the attorney whenever the document is cut. *Slice 1 shipped (`feat/context-budget`); slices 3–4 became the two compaction specs above; slices 2 and 5 are on the roadmap.*
- 2026-08-19 · [Eval harness — Tier 1 (deterministic regression armor)](2026-08-19-eval-harness-design.md) — a zero-LLM regression harness for the clause matcher and both edit parsers, gated on score-must-not-decrease. *Tier 1 shipped (`feat/eval-harness`); Tier 2 is on the roadmap.*
- 2026-08-14 · [Tester feedback capture](2026-08-14-tester-feedback-capture-design.md) — let an attorney flag a single turn from the pane and read the flags back, keyed to `turn_id` rather than the session. *Shipped (`feat/tester-feedback-capture`).*
- 2026-08-12 · [Repo cleanup + `legal_research` module split](2026-08-12-cleanup-and-legal-research-split-design.md) — remove dead code and stale docs, make the frontend test harness able to fail, and split the 952-line `legal_research` module. *Shipped (`chore/cleanup-and-legal-research-split`).*
- 2026-08-11 · [OpenTelemetry tracing migration](2026-08-11-otel-tracing-migration-design.md) — replace the Langfuse SDK with one OpenTelemetry instrumentation whose backend (Langfuse locally, Phoenix on the VM) is chosen by an env var. *Shipped (`feat/otel-tracing`).*
- 2026-08-10 · [Per-user identity + memory verification](2026-08-10-per-user-identity-and-memory-verification-design.md) — give each attorney a human-readable name alongside the per-install id, and verify that every memory store is partitioned per user. *Shipped (`feat/per-user-identity`); the SSO half waits for an Azure app.*
- 2026-07-23 · [VM / O365 deployment](2026-07-23-vm-o365-deployment-design.md) — host the pane and backend behind one reverse proxy on the VM, run the model on Spark, and sideload a production manifest to testers. *Bucket A shipped (`feat/vm-o365-deployment`); Bucket B mostly done (the pilot runs on it), a real hostname and trusted certificate remain on the roadmap.*
- 2026-07-23 · [Postgres store migration](2026-07-23-postgres-store-migration-design.md) — move the relational stores from SQLite to a dedicated `app-db` Postgres so several attorneys can write to one backend. *Shipped (`feat/postgres-store-migration`).*
- 2026-07-21 · [Attorney Preference Memory (`USER.md`)](2026-07-21-attorney-preference-memory-design.md) — a per-attorney preference file the attorney owns and the agent reads every turn and may only suggest additions to; stage 1 of the self-improving harness. *Stage 1 shipped (`feat/attorney-preference-memory`); later stages are the roadmap's north star.*
- 2026-07-16 · [Gate-Verdict Reconciliation](2026-07-16-gate-verdict-reconciliation-design.md) — reconcile the recalled No-Signature gate verdict too, so chat stops repeating a verdict that the filled fields no longer support. *Shipped (`feat/gate-verdict-reconciliation`).*
- 2026-07-15 · [Stale-Recall Reconciliation](2026-07-15-stale-recall-reconciliation-design.md) — drop recalled placeholder findings that the current document shows were filled after the review. *Shipped (`feat/stale-recall-reconciliation`).*
- 2026-07-15 · [O365 SSO Attorney Identity (Backend Foundation)](2026-07-15-o365-sso-attorney-identity-design.md) — derive the attorney from a verified O365 token instead of the `X-User-ID` header, config-gated and off by default. *Backend shipped, dormant (`feat/o365-sso-identity`); the client wiring waits for an Azure app (roadmap).*
- 2026-07-15 · [Server-Side Per-Attorney Conversation Store](2026-07-15-conversation-store-design.md) — keep chat conversations per document and attorney on the server, so they survive a pane reopen, a new session and another machine. *Shipped (`feat/conversation-store`).*
- 2026-07-14 · [Canonical document UUID](2026-07-14-canonical-document-uuid-design.md) — identify a document by a UUID stored in the document itself rather than a hash of its opening text, which changes as fields are filled. *Shipped (`feat/canonical-document-uuid`).*
- 2026-07-13 · [Chat persistence across pane reopen](2026-07-13-chat-persistence-pane-reopen-design.md) — restore the chat from `localStorage` when the pane reopens. *Superseded: built, then reverted on 2026-07-14; replaced by the canonical document UUID and the conversation store.*
- 2026-07-10 · [Calm "not found" message styling](2026-07-10-calm-notfound-styling-design.md) — show the benign "nothing to locate" message in a neutral style instead of the red error pill. *Shipped (`feat/calm-notfound-styling`).*
- 2026-07-09 · [Clause-locator hardening](2026-07-09-clause-locator-hardening-design.md) — whole-word matching and label-only findings in the Word clause locator, from the click-to-jump smoke test. *Shipped (`feat/clause-locator-hardening`).*
- 2026-07-07 · [Word add-in quick UX wins](2026-07-07-word-addin-quick-ux-design.md) — click a finding to jump to its clause, and filter and sort findings. *Shipped (`feat/word-addin-quick-ux`).*
- 2026-06-29 · [Chat memory & grounding](2026-06-29-chat-memory-grounding-design.md) — give the Chat tab what the Findings tab has: the stored review, the playbook and the governing MSA, under a context cap, in four phases. *Shipped (`feat/chat-memory-grounding`).*
- 2026-06-18 · [SOW-vs-MSA Review](2026-06-18-sow-vs-msa-review-design.md) — when a review detects a SOW, attach the governing MSA from Qdrant and flag the SOW terms that conflict with it. *Shipped (`feat/sow-vs-msa-review`).*
- 2026-05-20 · [Resume After Interrupt](2026-05-20-resume-after-interrupt-design.md) — pause the graph at `human_review` and resume it with the attorney's verdict, including a request-changes loop. *Shipped (`feat/resume-after-interrupt`).*
- 2026-05-19 · [Within-Session Conversation Memory](2026-05-19-within-session-memory-design.md) — give the model a bounded history of earlier turns in the same session through the Redis checkpointer. *Shipped (`feat/within-session-memory`).*
- 2026-05-06 · [Legal Plugin — Design Spec](2026-05-06-legal-plugin-design.md) — the original design: Chainlit and FastAPI in front of a LangGraph supervisor that routes to skills, with a shared RAG layer and a local model. *Built before the shipped log starts (2026-05-15).*
