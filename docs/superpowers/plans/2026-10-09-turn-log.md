# Per-turn record (`turn_log`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One durable Postgres row per accepted request to `/api/query`, its resume and `/api/compact` — failures included — recording who/when/which document, the outcome, what grounded the answer, where the time went, and which Word, pane build and backend build sent it.

**Architecture:** A per-request facts collector in `observability/spans.py` (same lifecycle as the reason-code accumulator, fed before any `is_recording()` guard) gathers model calls, the first failure and grounding facts from inside the graph. Every handler exit goes through `api/turn_record.py::finish_turn`, which stamps `app.outcome` and builds the row from that same value with a pure `memory/turn_log.py::build_turn_row`, then writes it quietly after the response via FastAPI `BackgroundTasks`. The pane sends `X-Office-Platform` / `X-Office-Version` / `X-Pane-Build` on every request; both images learn their commit from a `BUILD_SHA` build argument passed by the deploy command.

**Tech Stack:** Python 3.12 (uv), FastAPI 0.136.1, LangGraph 0.6, psycopg 3 + psycopg_pool, OpenTelemetry SDK, pytest + testcontainers (Postgres 17.10); Word add-in in React + TypeScript + Vite 5, tests run with `tsx`; Docker / docker compose.

**Spec:** [`docs/superpowers/specs/2026-10-09-turn-log-design.md`](../specs/2026-10-09-turn-log-design.md) — read it first; this plan implements it and argues from it.

## Global Constraints

- **Python 3.12 via uv.** Run everything as `uv run …`. **No new dependencies** — `psycopg.types.json.Jsonb` and `fastapi.BackgroundTasks` are already installed; `scripts/check_locks.py` must stay green.
- **All imports at the top of the file** (CLAUDE.md hard rule 1). No imports inside functions in production code.
- **No backwards-compat shims** (CLAUDE.md hard rule 5): when a signature changes, change the call sites.
- **Recording must never break or slow a turn.** Building the row is guarded; writing it is quiet and happens after the response.
- **The collector is fed BEFORE any `is_recording()` guard** — the row must be identical with tracing off.
- **No new degradation codes.** The vocabulary stays at 23 (`observability/degradations.py`); a turn_log failure is class 4 and records no code.
- **Caps:** `request` 2,000 chars; `error` 2,000 chars; each of the three pane headers 64 chars; `User-Agent` 300 chars.
- **Header names, exactly:** `X-Office-Platform`, `X-Office-Version`, `X-Pane-Build`.
- **Build ids:** `dev` for local runs and the Vite dev server; `unknown` when an image is built without `BUILD_SHA`; the short commit (`git rev-parse --short HEAD`) when deployed.
- **`turn_log.timestamp` is when the request ARRIVED**, as `datetime.now(timezone.utc).isoformat()` — the same format every other table uses, so lexicographic `>=` filters stay correct.
- **`tests/conftest.py` truncates a hardcoded table list** — `turn_log` must be added to it, or state leaks between tests.
- **In tests, never `import skills.legal_research.legal_research as X`** — use `importlib.import_module(...)` (CLAUDE.md: `__init__.py` re-exports the function over the submodule).
- **Tests need Docker running** (testcontainers starts Postgres once per session).
- **Word add-in changes need a sideload check in Word for Mac** — `tsc` is not enough (CLAUDE.md).
- **Nothing on the VM without the owner's explicit OK for that step, and their choice of who runs it** (CLAUDE.md hard rule 6). This plan ends at a reviewed branch; the Rollout section is reference for later.
- **Every commit message ends with** `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

- Consumes: nothing new.

  - `mark_failed(reason, exc=, detail=)` sets `"error"` once: `"{reason}: {ExcClass}: {exc}"`, else `"{reason}: {detail}"`, else `"{reason}"`.

```python
def note_turn(**facts: Any) -> None:
    """Record facts about this request for its turn_log row. Never raises.

    The last write of a key wins; outside a request root it is a no-op. Like
    _accumulate it ignores whether a span is recording: the row must come out
    the same with tracing off."""
    try:
        acc = _root_turn.get()
        if acc is not None:
            acc.update(facts)
    except Exception:
        pass


def turn_facts() -> dict:
    """What this request has recorded so far, for its turn_log row. A copy —
    read it before the root span closes, which resets it."""
    acc = _root_turn.get() or {}
    out = dict(acc)
    if "llm_detail" in out:
        out["llm_detail"] = [dict(call) for call in out["llm_detail"]]
    return out


def _record_llm_call(
    name: str | None, model: str | None, usage: dict | None, timings: dict | None,
) -> None:
    """Append one model call to the request's llm_detail. Never raises."""
    try:
        acc = _root_turn.get()
        if acc is None:
            return
        usage = usage or {}
        timings = timings or {}
        acc.setdefault("llm_detail", []).append({
            "name": name or "",
            "model": model or "",
            "tokens_in": usage.get("input"),
            "tokens_out": usage.get("output"),
            "load_ms": timings.get("load_ms"),
            "prompt_ms": timings.get("prompt_eval_ms"),
            "gen_ms": timings.get("eval_ms"),
            "total_ms": timings.get("total_ms"),
        })
    except Exception:
        pass


def _note_first_error(reason: str, exc: BaseException | None, detail: str) -> None:
    """Keep the FIRST failure's message: it is what broke; later ones are
    usually its consequences. Never raises."""
    try:
        acc = _root_turn.get()
        if acc is None or acc.get("error"):
            return
        if exc is not None:
            acc["error"] = f"{reason}: {exc.__class__.__name__}: {exc}"
        elif detail:
            acc["error"] = f"{reason}: {detail}"
        else:
            acc["error"] = reason
    except Exception:
        pass
```

```python
"""turn_log — one durable row per accepted request (spec 2026-10-09).

Who asked, when, on which document; did it work; what grounded it; where the
time went; what sent it. Phoenix keeps the full prompt and the span tree for
drill-down; this table is the system of record.

The write is QUIET, like interaction_event: it runs after the response has
gone out (api/turn_record.py), so there is nobody left to tell, and telemetry
must never break a turn. A failed write puts the whole row in the log instead.
"""
from __future__ import annotations

import hashlib
import json
import logging
from typing import Any

from psycopg.types.json import Jsonb

from memory.db import get_pool

logger = logging.getLogger(__name__)

# INSERT order. build_turn_row returns exactly these keys — tests pin that, so
# the two cannot drift apart.
COLUMNS: tuple[str, ...] = (
    "timestamp", "turn_id", "trace_id", "kind", "session_id", "document_id",
    "attorney_id", "user_name",
    "task_type", "request", "doc_chars", "doc_sha256",
    "status", "outcome", "degradations", "error", "awaiting_review",
    "contract_type", "contract_type_defaulted", "msa_title", "preferences_chars",
    "doc_kept_pct", "context",
    "duration_ms", "llm_calls", "llm_load_ms", "llm_prompt_ms", "llm_gen_ms",
    "tokens_in", "tokens_out", "llm_detail",
    "response_chars", "edits_proposed", "preferences_proposed", "compaction",
    "office_platform", "office_version", "pane_build", "backend_build", "user_agent",
)
_JSON_COLUMNS = frozenset({"degradations", "context", "llm_detail", "compaction"})

_REQUEST_CAP = 2000
_ERROR_CAP = 2000


def _fingerprint(text: str) -> tuple[int, str]:
    """(chars, hex SHA-256 of the UTF-8 text): the document without the document.
    surrogatepass, because broken UTF-16 from Word reaches Python as lone
    surrogates that plain UTF-8 refuses to encode."""
    if not text:
        return 0, ""
    return len(text), hashlib.sha256(text.encode("utf-8", "surrogatepass")).hexdigest()


def _storable(text: str) -> str:
    """Free text Postgres can store: a lone surrogate becomes '?'."""
    return (text or "").encode("utf-8", "replace").decode("utf-8")


def _total(calls: list[dict], key: str) -> int:
    return sum(int(call.get(key) or 0) for call in calls)


def build_turn_row(
    *,
    kind: str,
    turn_id: str,
    trace_id: str,
    arrived_at: str,
    duration_ms: int,
    attorney_id: str,
    user_name: str,
    session_id: str,
    document_id: str,
    task_type: str,
    request: str,
    doc_text: str,
    status: str,
    outcome: str,
    degradations: list[str],
    api_error: str,
    awaiting_review: bool,
    facts: dict,
    result: dict | None,
    compaction: dict | None,
    client: dict,
    backend_build: str,
) -> dict[str, Any]:
    """One turn_log row. Pure: no I/O, no settings, no clock.

    `result` is the graph's final state, or None when nothing came back (the
    graph raised, a resume found no session, a compaction). Where it exists it
    wins over the request for document_id (intake resolves the preamble-hash
    fallback) and task_type (what actually ran). `facts` is
    observability.spans.turn_facts(); `client` holds ClientInfo's four fields.
    """
    state = result or {}
    calls = [dict(call) for call in facts.get("llm_detail") or []]
    doc_chars, doc_sha256 = _fingerprint(doc_text)
    truncated = state.get("context_truncated")
    return {
        "timestamp": arrived_at,
        "turn_id": turn_id,
        "trace_id": trace_id,
        "kind": kind,
        "session_id": session_id,
        "document_id": state.get("document_id") or document_id,
        "attorney_id": attorney_id,
        "user_name": user_name,
        "task_type": state.get("task_type") or task_type,
        "request": _storable(request)[:_REQUEST_CAP],
        "doc_chars": doc_chars,
        "doc_sha256": doc_sha256,
        "status": status,
        "outcome": outcome,
        "degradations": list(degradations),
        # The first failure the turn recorded says what broke; the API's own
        # error text is the fallback for exits that never called mark_failed
        # (a resume whose session had expired).
        "error": _storable(facts.get("error") or api_error)[:_ERROR_CAP],
        "awaiting_review": bool(awaiting_review),
        "contract_type": facts.get("contract_type", ""),
        "contract_type_defaulted": bool(facts.get("contract_type_defaulted", False)),
        "msa_title": facts.get("msa_title", ""),
        "preferences_chars": int(facts.get("preferences_chars", 0)),
        "doc_kept_pct": truncated.get("kept_pct") if isinstance(truncated, dict) else None,
        "context": state.get("context_breakdown") or None,
        "duration_ms": max(0, int(duration_ms)),
        "llm_calls": len(calls),
        "llm_load_ms": _total(calls, "load_ms"),
        "llm_prompt_ms": _total(calls, "prompt_ms"),
        "llm_gen_ms": _total(calls, "gen_ms"),
        "tokens_in": _total(calls, "tokens_in"),
        "tokens_out": _total(calls, "tokens_out"),
        "llm_detail": calls,
        "response_chars": len(state.get("llm_response") or ""),
        "edits_proposed": len(state.get("proposed_edits") or []),
        "preferences_proposed": len(state.get("proposed_preferences") or []),
        "compaction": compaction,
        "office_platform": client.get("office_platform", ""),
        "office_version": client.get("office_version", ""),
        "pane_build": client.get("pane_build", ""),
        "backend_build": backend_build,
        "user_agent": client.get("user_agent", ""),
    }


def write_turn(row: dict[str, Any]) -> None:
    """INSERT one row. RAISES — the quiet policy lives in write_turn_quietly.

    Deliberately not @traced: it runs after the response, outside the request's
    span, where a span would start an orphan trace of its own on every turn."""
    values = [
        Jsonb(row[column]) if column in _JSON_COLUMNS and row[column] is not None else row[column]
        for column in COLUMNS
    ]
    with get_pool().connection() as conn:
        conn.execute(
            f"INSERT INTO turn_log ({', '.join(COLUMNS)}) "
            f"VALUES ({', '.join(['%s'] * len(COLUMNS))})",
            values,
        )


def write_turn_quietly(row: dict[str, Any]) -> None:
    """write_turn that never raises. A failure logs the whole row at ERROR —
    journald keeps it, so the turn stays recoverable — and nothing else
    happens: no reason code (class 4, telemetry's own failure), no banner."""
    try:
        write_turn(row)
    except Exception as e:
        logger.error(
            "TURN LOG WRITE FAILED (%s) — row recorded here instead: %s",
            e, json.dumps(row, default=str, ensure_ascii=False),
        )
```

```python
"""What sent a request: the Word host, the pane build, the webview.

The pane sends three headers on every request (clients/word/src/requestHeaders.ts);
User-Agent arrives on its own, passed through by Caddy. Read-only facts for the
turn_log row and the trace — never identity, never a key, never a reason to
reject a request: a missing header is just "".

_HEADER_CAP = 64        # platform, version and build are short, and headers are client-controlled
_USER_AGENT_CAP = 300


@dataclass(frozen=True)

    office_platform: str = ""
    office_version: str = ""
    pane_build: str = ""
    user_agent: str = ""

    user_agent: str = Header("", alias="User-Agent"),

    """The request's client facts, each capped."""

        office_platform=x_office_platform[:_HEADER_CAP],
        office_version=x_office_version[:_HEADER_CAP],
        pane_build=x_pane_build[:_HEADER_CAP],
        user_agent=user_agent[:_USER_AGENT_CAP],
    )
```

```python
def call_handler(fn, *args, **kwargs):
    """Call a route handler as a plain function, the way FastAPI would.

    Supplies what FastAPI injects and a direct call would not — BackgroundTasks
    and the request's ClientInfo — then runs the background tasks, as FastAPI
    does after sending the response. A handler that raises propagates and its
    tasks never run: FastAPI behaves the same way, which is why raising exits
    write their turn_log row synchronously."""
    tasks = kwargs.setdefault("background_tasks", BackgroundTasks())
    kwargs.setdefault("client", ClientInfo())
    response = fn(*args, **kwargs)
    for task in tasks.tasks:
        task.func(*task.args, **task.kwargs)
    return response
```

```python
# api/turn_record.py
"""The one exit path every request handler goes through (spec 2026-10-09, D3).

finish_turn stamps app.outcome AND builds the turn_log row from that same
value, so the row and the trace cannot disagree about how a turn went. The row
is written after the response (BackgroundTasks) — the attorney waits for
nothing — except on exits that raise, which skip background tasks and so
write it now.
"""
from __future__ import annotations

import logging
import time
from dataclasses import asdict
from datetime import datetime, timezone

from fastapi import BackgroundTasks

from api.client_info import ClientInfo
from config import get_settings
from memory.turn_log import build_turn_row, write_turn_quietly
from observability.spans import (
    current_trace_id, degradations, set_outcome, set_trace_attributes, turn_facts,
)

logger = logging.getLogger(__name__)


def start_turn(
    *,
    kind: str,
    turn_id: str,
    client: ClientInfo,
    attorney_id: str = "",
    user_name: str = "",
    session_id: str = "",
    document_id: str = "",
    task_type: str = "",
    request: str = "",
    doc_text: str = "",
) -> dict:
    """What is known when the request arrives. Call first thing inside the
    handler's root span; it also stamps the client facts on the trace."""
    backend_build = get_settings().build_sha
    set_trace_attributes(metadata={
        "turn_id": turn_id,
        "office.platform": client.office_platform,
        "office.version": client.office_version,
        "pane.build": client.pane_build,
        "backend.build": backend_build,
    })
    return {
        "kind": kind, "turn_id": turn_id, "trace_id": current_trace_id(),
        "arrived_at": datetime.now(timezone.utc).isoformat(),
        "started": time.monotonic(),
        "client": asdict(client), "backend_build": backend_build,
        "attorney_id": attorney_id, "user_name": user_name,
        "session_id": session_id, "document_id": document_id,
        "task_type": task_type, "request": request, "doc_text": doc_text,
    }


def finish_turn(
    turn: dict,
    *,
    outcome: str,
    status: str,
    api_error: str = "",
    awaiting_review: bool = False,
    result: dict | None = None,
    compaction: dict | None = None,
    background_tasks: BackgroundTasks | None = None,
) -> None:
    """Stamp app.outcome and record the turn. Never raises.

    Must run inside the root span: degradations() and turn_facts() are reset
    when it closes. With background_tasks the write happens after the
    response; without (an exit about to raise) it happens now.
    """
    set_outcome(outcome)
    try:
        row = build_turn_row(
            kind=turn["kind"], turn_id=turn["turn_id"], trace_id=turn["trace_id"],
            arrived_at=turn["arrived_at"],
            duration_ms=round((time.monotonic() - turn["started"]) * 1000),
            attorney_id=turn["attorney_id"], user_name=turn["user_name"],
            session_id=turn["session_id"], document_id=turn["document_id"],
            task_type=turn["task_type"], request=turn["request"], doc_text=turn["doc_text"],
            status=status, outcome=outcome, degradations=degradations(),
            api_error=api_error, awaiting_review=awaiting_review,
            facts=turn_facts(), result=result, compaction=compaction,
            client=turn["client"], backend_build=turn["backend_build"],
        )
    except Exception:
        logger.exception(
            "[turn_log] could not build the row for turn %s — the response is unaffected",
            turn.get("turn_id"),
        )
        return
    if background_tasks is not None:
        background_tasks.add_task(write_turn_quietly, row)
    else:
        write_turn_quietly(row)
```

```ts
// Headers every backend call sends: who is asking (attorneyIdentity.ts) and
// what is asking — the Word host and the pane build — so each turn_log row can
// say which Word and which bundle sent it (spec 2026-10-09). Never a key and
// never a reason to fail a request: an unreadable value is sent empty.
import { userHeaders } from "./attorneyIdentity";

const HEADER_CAP = 64;

/** fetch throws a TypeError on a header value outside Latin-1, and a control
 *  character is never part of a platform or a version — keep printable ASCII. */
function headerSafe(value: string): string {
  return value.replace(/[^\x20-\x7E]/g, "").slice(0, HEADER_CAP);
}

/** The commit this bundle was built from; "dev" outside a Vite build. */
export function paneBuild(): string {
  return typeof __PANE_BUILD__ === "string" ? __PANE_BUILD__ : "dev";
}

/** Office's own diagnostics (Mac / PC / OfficeOnline and the Word build) and the pane build. */
export function clientHeaders(): Record<string, string> {
  let platform = "";
  let version = "";
  try {
    const diagnostics = Office.context.diagnostics;
    platform = String(diagnostics.platform || "");
    version = String(diagnostics.version || "");
  } catch {
    /* no Office host (tests, the eval runner) or no diagnostics yet — send empty */
  }
  return {
    "X-Office-Platform": headerSafe(platform),
    "X-Office-Version": headerSafe(version),
    "X-Pane-Build": headerSafe(paneBuild()),
  };
}

/** Everything a backend call sends besides Content-Type. */
export function requestHeaders(): Record<string, string> {
  return { ...userHeaders(), ...clientHeaders() };
}
```

```python
def recent_turns(
    *, since: str = "", attorney_id: str = "", document_id: str = "", limit: int = 200,
) -> list[dict[str, Any]]:
    """The newest `limit` turns within the filter, oldest first, each with what
    the attorney then did with it: Apply / failure / Discard events and flags
    written against the same turn_id."""
    where, params = _filters(since, document_id, attorney_id)
    sql = f"""
        SELECT * FROM (
            SELECT t.*,
                (SELECT count(*) FROM interaction_event e WHERE e.turn_id = t.turn_id
                   AND e.action IN ('edit_applied', 'redline_applied')) AS applied,
                (SELECT count(*) FROM interaction_event e WHERE e.turn_id = t.turn_id
                   AND e.action IN ('edit_failed', 'redline_failed')) AS failed,
                (SELECT count(*) FROM interaction_event e WHERE e.turn_id = t.turn_id
                   AND e.action = 'edit_discarded') AS discarded,
                (SELECT count(*) FROM feedback f WHERE f.turn_id = t.turn_id) AS flags
            FROM turn_log t
            {"WHERE " + where if where else ""}
            ORDER BY t.id DESC
            LIMIT %s
        ) newest
        ORDER BY id
    """
    with get_pool().connection() as conn:
        cur = conn.execute(sql, [*params, limit])
        names = [column.name for column in cur.description]
        return [dict(zip(names, values)) for values in cur.fetchall()]
```

```python
def _secs(ms: int) -> str:

def format_turn(t: dict) -> list[str]:
    """One turn as the timeline prints it: what happened, where the time went,
    what grounded it, what the attorney did with it, what sent it, and the
    question with the ids to look it up by."""
    task = t["task_type"] or t["kind"]
    codes = f" [{', '.join(t['degradations'])}]" if t["degradations"] else ""
    who = t["user_name"] or t["attorney_id"]
    lines = [f"  {t['timestamp'][:19]}  {who}  {t['kind']}:{task}  {t['outcome']}{codes}"]
    if t["error"]:
        lines.append(f"    error: {t['error'][:160]}")
    lines.append(
        f"    {_secs(t['duration_ms'])} total · {t['llm_calls']} model call(s): "
        f"load {_secs(t['llm_load_ms'])} · prompt {_secs(t['llm_prompt_ms'])} · "
        f"gen {_secs(t['llm_gen_ms'])} · {t['tokens_in']}→{t['tokens_out']} tokens"
    )
    grounding = t["contract_type"] or "no playbook"
    if t["contract_type_defaulted"]:
        grounding += " (type defaulted)"
    grounding += f" · MSA: {t['msa_title'] or '—'}"
    if t["doc_kept_pct"] is not None:
        grounding += f" · document cut to {t['doc_kept_pct']}%"
    lines.append(f"    {grounding} · doc {t['doc_chars']} chars")
    lines.append(
        f"    edits {t['edits_proposed']} proposed → {t['applied']} applied, "
        f"{t['failed']} failed, {t['discarded']} discarded · flags {t['flags']}"
    )
    # An empty pane_build is a pane from before SP2 (or Chainlit) — unknown,
    # not stale. Only two different builds are a stale pane.
    stale = ("  ⚠ stale pane"
             if t["pane_build"] and t["pane_build"] != t["backend_build"] else "")
    sender = t["office_platform"] or "no Office headers"
    if t["office_version"]:
        sender += f" {t['office_version']}"
    lines.append(
        f"    {sender} · pane {t['pane_build'] or '—'} · backend {t['backend_build']}{stale}"
    )
    if t["request"]:
        lines.append(f"    asked: {t['request'][:100]}")
    trace = f"  trace: {t['trace_id']}" if t["trace_id"] else ""
    lines.append(f"    turn: {t['turn_id']}{trace}")
    return lines


def print_turns(rows: list[dict]) -> None:
```
